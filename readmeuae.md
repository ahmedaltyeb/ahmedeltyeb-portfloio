

# Ahmed's Digital Canvas

A modern portfolio website built to showcase frontend development skills, real projects, and professional experience.

Designed for performance, clean UI, and strong presentation.

---

## Overview

This project is a personal portfolio for Ahmed Eltyeb Khalifa, a Frontend Developer based in UAE.

It presents:

* Real projects with live links
* Technical skills
* Work experience timeline
* Contact and lead generation

Target users:

* Employers
* Clients
* Collaborators

Purpose:

* Convert visitors into job opportunities or clients
* Show real capabilities through UI, code, and structure

---

## Key Features

* Hero section with clear personal branding
* Smooth navigation with scroll-based sections
* Dark and light mode with persistent state
* Projects showcase with tech stack and links
* Skills grouped by category
* Experience timeline with structured data
* Testimonials carousel
* Animated partners section
* Contact form with validation and toast feedback
* Fully responsive across all devices
* Smooth animations using Framer Motion
* Accessible UI using Radix components
* SEO-friendly structure

---

## Tech Stack

Frontend:

* React 18
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Radix UI
* Framer Motion
* React Router

Forms and Data:

* React Hook Form
* React Query

Tools:

* ESLint
* PostCSS
* Bun or npm

Deployment:

* GitHub Pages
* gh-pages

## Project Structure



Main structure:

* src/components
  UI sections like Hero, Skills, Projects, Contact

* src/pages
  Main pages like Home and 404

* src/hooks
  Custom logic like scroll detection and toast system

* src/lib
  Utility functions

* src/assets
  Images and static resources

* App.tsx
  Routing and layout

* main.tsx
  Entry point

---

## Getting Started

Installation:

* git clone <YOUR_GIT_URL>
* cd project-folder
* npm install

Run development server:

* npm run dev

Build for production:

* npm run build

Preview build:

* npm run preview

---

## Environment Setup

No .env required for basic usage.

Optional customization:

* API endpoints inside components
* Theme colors in src/index.css
* Base path in vite.config.ts
