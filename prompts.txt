#  (2- prompt - :update Hero Scetion )


Use this prompt with your AI agent:

Update only the Hero section of my existing portfolio website.

Goal

Add a smooth text-switching animation in the hero content area so the role and description rotate automatically between two identities without changing the current design.

Current text in hero:
"Front End Web Developer"
"Building responsive, user-centric web interfaces with seamless UI/UX. Specializing in React.js, JavaScript, and modern CSS frameworks."

New behavior required

The hero must alternate between two content states:

State 1
Title:
Front End Web Developer

Description:
Building responsive, user-centric web interfaces with seamless UI/UX. Specializing in React.js, JavaScript, and modern CSS frameworks.

State 2
Title:
Digital Marketer

Description:
Driving business growth through performance marketing, paid campaigns, lead generation, content strategy, and data-driven optimization.

Animation requirements

Do not remove the current hero layout.
Do not redesign anything.
Keep the same font sizes, colors, spacing, and alignment.
Only animate the role text and description text.

The text must switch automatically every few seconds.
Use smooth fade and slide animation.
No harsh jump.
No typing effect.
No flashy animation.
The transition must feel clean, modern, and professional.

Behavior details

Show the first text by default.
After around 3 to 4 seconds, transition smoothly to the second text.
Then loop back to the first text.
Keep the animation infinite.
Both title and description must animate together as one content block.

Technical requirements

This project uses:
React 18
TypeScript
Vite
Tailwind CSS
Framer Motion

Use Framer Motion for the animation.
Do not add a new library.

Implementation guidance

Edit the existing Hero component only.
Create a small array of hero roles and descriptions.
Use React state plus setInterval or a similar clean approach to rotate content.
Use AnimatePresence and motion.div from Framer Motion for smooth enter and exit animation.
Make sure the animation does not cause layout shift or break responsiveness.
Keep the height stable so the hero content does not jump when text changes.

Suggested content structure

const heroRoles = [
{
title: "Front End Web Developer",
description: "Building responsive, user-centric web interfaces with seamless UI/UX. Specializing in React.js, JavaScript, and modern CSS frameworks."
},
{
title: "Digital Marketer",
description: "Driving business growth through performance marketing, paid campaigns, lead generation, content strategy, and data-driven optimization."
}
];

Suggested animation style

Enter:
opacity 0
y 12

Animate:
opacity 1
y 0

Exit:
opacity 0
y -12

Use a smooth duration around 0.4 to 0.7 seconds.
Rotate content every 3500 to 4000 milliseconds.

Important constraints

Do not change buttons.
Do not change profile image.
Do not change social icons.
Do not change hero structure.
Do not change background.
Do not change navbar.

Output required from the agent

Return:

1. The updated Hero component code
2. A short note explaining where the rotating text logic was added
3. Any small styling adjustment used to prevent layout jump

If the current Hero component already uses motion, integrate the new logic into the existing structure instead of rewriting the whole component.
